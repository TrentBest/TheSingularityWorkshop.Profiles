# Profiles documentation index

## 01 — What

Profiles is a provider-neutral domain library for entity profiles, typed claims, disclosure rules, and observer-specific representations. This index routes readers to the authoritative explanation for each topic.

## 02 — Why

The documentation separates consumer tasks, domain contracts, architecture, privacy boundaries, theory, API structure, and UML. Read the focused authority rather than relying on duplicated summaries.
